# Учёт трат

Минималистичное приложение для добавления, поиска и фильтрации расходов. Бэкенд написан на Go.

## Локальный запуск

```bash
go run .
```

Откройте `http://localhost:8080`. Без переменной `DATABASE_URL` данные сохраняются локально в `data/expenses.json`.

## Развёртывание

Проект подготовлен для Docker-хостинга. В облаке задайте переменную окружения `DATABASE_URL` со строкой подключения PostgreSQL. Таблица создаётся автоматически при первом запуске.
